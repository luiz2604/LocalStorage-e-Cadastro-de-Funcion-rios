## Sobre o projeto

Este projeto foi desenvolvido como atividade prática
para aprender a utilizar HTML, CSS e JavaScript.

O sistema permite cadastrar funcionários,
listar os funcionários em cards e salvar os dados
no LocalStorage do navegador.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- LocalStorage
- Visual Studio Code

## Funcionalidades

- Cadastro de funcionários
- Listagem de funcionários
- Exibição da quantidade de funcionários
- Salvamento dos dados no LocalStorage
- Recuperação dos dados após atualizar a página
